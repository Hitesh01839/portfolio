# Hitesh Ganga — Portfolio

Personal portfolio of **Hitesh Ganga**, focused on cybersecurity, software, systems, and security experimentation.

The site explores the intersection of:

- Cybersecurity & penetration testing
- Linux & systems
- Web security
- Software development
- Android / AOSP
- Security research & experiments

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- GSAP
- Lenis
- Lucide React

## Features

- GSAP-powered motion and scroll interactions
- Smooth scrolling with Lenis
- Custom cursor and magnetic interactions
- Scroll-based project transitions
- Animated preloader
- Responsive design
- Reduced-motion support
- SEO metadata
- Accessible navigation
